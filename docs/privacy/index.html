6Device Permissions & Technologies Used

The app only requests permissions that are necessary for its functionality:

  • Camera (optional): Used exclusively for optional QR code scanning when using external hardware in the online game mode. The camera is only activated on explicit user action, and no image data is stored or transmitted.
Note on technical components

For communication between smartphone and smartwatch (Wear OS), the Google Play Services Wearable SDK is used. For QR code detection on Android, the Google ML Kit Barcode Scanning SDK is used. These components are used solely for the mentioned functions and do not collect any personal data. On iOS, QR code detection uses only Apple's native frameworks (AVFoundation/Vision).
